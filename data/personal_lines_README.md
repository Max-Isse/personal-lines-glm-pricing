# Simulated Personal Lines (Motor) dataset

> **This is synthetic data.** It was generated by `pricing/generate_data.py` to
> demonstrate GLM frequency-severity pricing technique. It is not real
> underwriting or claims data, and the effect sizes are illustrative, not
> calibrated to any insurer's experience.

Regenerate it (deterministic, seed 42) with:

```bash
python -m pricing.generate_data
```

This writes `data/motor_policies.csv` (150,000 policy-years, ~12 MB). The CSV is
git-ignored because the script reproduces it exactly.

## Portfolio at a glance

| Metric | Value |
|---|---|
| Policies | 150,000 |
| Earned exposure | 132,216 vehicle-years |
| Claims | 9,476 |
| Claim frequency | 7.2% per vehicle-year |
| Mean severity | £3,098 per claim |
| Burning cost | £222 per vehicle-year |

## Columns

| Column | Description |
|---|---|
| `policy_id` | Row identifier |
| `driver_age` | Main driver age, 17-88 |
| `ncd_years` | No-claims discount years, 0-15 (can't exceed `driver_age - 17`) |
| `vehicle_group` | `VG1` (small, cheap) to `VG5` (powerful, expensive): a simplified version of the ABI 1-50 groups |
| `region` | London, South East, Midlands, North, Scotland, Wales |
| `mileage_band` | Declared annual mileage: `<5k`, `5-10k`, `10-15k`, `15k+` |
| `exposure` | Years at risk in the record (0.05-1.0). 75% are full-year; 25% are part-year (mid-term new business or cancellations) |
| `claim_count` | Number of claims in the exposure period |
| `claim_cost` | Total incurred cost of those claims (£) |
| `true_frequency` | **Truth, for validation only.** Expected claims per vehicle-year |
| `true_severity` | **Truth, for validation only.** Expected cost per claim |
| `true_pure_premium` | **Truth, for validation only.** `true_frequency * true_severity` |

The `true_*` columns are never used as model inputs. They exist so Phase C can
check how well the fitted technical price recovers the risk that generated the
data. Real data never gives you this.

The pricing scripts derive the banded rating factors (`age_band`, `ncd_band`) and
the `young_high_vg` interaction flag from the raw columns (see `pricing/config.py`).

## Simulation assumptions

All effects are **multiplicative**. That is the structure a log-link GLM assumes,
so a well-specified GLM should recover them.

### Claim frequency (claims per vehicle-year)

`frequency = 0.085 x age(age) x ncd(ncd) x vehicle_group x region x mileage x interaction`

| Factor | True relativity |
|---|---|
| Driver age | Smooth U-curve: `1 + 1.8*exp(-(age-17)/5) + 0.5*max(0, (age-70)/10)`, normalised to age 45. About 2.8x at 17, 1.6x at 22, 1.1x at 30, flat through middle age, rising to about 1.5x at 85 |
| No-claims years | `exp(-0.07 * min(ncd, 9))`: about 7% off per year, capped at 9 years (0.53x) |
| Vehicle group | VG1 0.85, VG2 0.95, **VG3 1.00**, VG4 1.15, VG5 1.35 |
| Region | London 1.30, South East 1.05, **Midlands 1.00**, North 1.08, Scotland 0.85, Wales 0.90 |
| Mileage | <5k 0.75, **5-10k 1.00**, 10-15k 1.20, 15k+ 1.45 |
| Interaction | Driver under 25 **and** VG4/VG5: an extra **x1.35** on top of the main effects |

**Overdispersion.** Each policy's Poisson mean is multiplied by an unobserved
Gamma(2, 0.5) "frailty" (mean 1). This represents risk differences the rating
factors don't capture, such as driving style. Claim counts are then Negative
Binomial with alpha = 0.5, which is typical of real motor data. It lets Phase B
compare Poisson and Negative Binomial.

**Exposure.** Counts are drawn as `Poisson(frequency x exposure x frailty)`, so a
half-year policy has half the expected claims. This is why the frequency GLM
uses `log(exposure)` as an offset.

### Claim severity (cost per claim, £)

`severity = 2,800 x vehicle_group x region x young_driver`

| Factor | True relativity |
|---|---|
| Vehicle group | VG1 0.80, VG2 0.90, **VG3 1.00**, VG4 1.20, VG5 1.50 |
| Region | London 1.35, South East 1.15, **Midlands 1.00**, North 0.92, Scotland 0.85, Wales 0.90 |
| Young driver (<25) | x1.15 |
| NCD, mileage | **No effect.** A correct severity model should find these insignificant |

Individual claim costs are Gamma distributed with shape 1.5 (coefficient of
variation ~0.82). A policy's total cost is the sum of its claims.

### Portfolio mix (correlations between rating factors)

The rating factors are not independent. That is realistic, and it is the reason
a one-way analysis is misleading and a multivariate GLM is needed:

- 10% of drivers are 17-24; the rest follow a Normal(47, 14) age distribution clipped to 25-88.
- NCD years are capped by driving history, so young drivers have little or no NCD.
  Age and NCD are strongly correlated.
- Young drivers are skewed toward cheaper vehicle groups (35% VG1 vs 18% for adults).
- London drivers declare lower mileage (35% under 5k vs 18% elsewhere).

For example, a one-way view of London mixes a high true frequency with a
low-mileage mix. The GLM separates the two.

## What this data deliberately does *not* model

- IBNR / claims development. All claims are treated as fully developed and
  ultimate. In practice you would develop claims to ultimate before modelling.
- Large-loss capping. There is no large-bodily-injury tail. Real pipelines cap
  or separately model large losses.
- Peril split (own damage, third-party property, bodily injury, windscreen, theft).
  Here there is a single all-perils claim.
- Inflation and trend. There is a single cohort with no calendar-year effects.
- Rate, expense and profit loadings. The model output is a technical (risk) price
  only, not a street price.
